# Predicting-Anatomical-Brain-Tumor-Growth
## Overview

This repository is linked to the research project on guided denoising diffusion models for brain tumor MRI. The main implementation and research work can be found in the external repository.

## External Repository

The full research project, implementation, and methodology are available at:

**[Guided Denoising Diffusion Models for Brain Tumor MRI](https://gitlab.ethz.ch/BMDSlab/publications/oncology/guided-denoising-diffusion-models-for-brain-tumor-mri.git)**

## About

This project focuses on predicting anatomical brain tumor growth using advanced machine learning techniques, specifically leveraging guided denoising diffusion models applied to brain tumor MRI data.

For detailed information about the methods, experiments, and results, please refer to the main repository linked above.
